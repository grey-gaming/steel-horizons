# Game Design Documents

The numbered V1 GDDs are approved and read in order from 01 through 14. Authority for overlapping implementation details is:

1. `12-simulation-foundations.md` — simulation rules and formulas
2. `13-data-models.md` — serialized core shapes
3. `14-authored-content.md` — exact costs, statistics, recipes, technologies, and starting data

Documents 01–11 describe product intent, progression, presentation, and interactions and must remain consistent with those canonical contracts. `v2-gate-logistics.md` is a future concept, not a V1 specification.
